# GitHub Actions used in the EMO-BON workflow

The observatory `workflow.yml` (the one we ran in Exercise 1) calls a mix of actions:

- **1 official GitHub action**: `actions/checkout`
- **2 third-party public actions** (not written by EMO-BON): `stefanzweifel/git-auto-commit-action`, `peaceiris/actions-gh-pages`
- **4 custom EMO-BON actions**: `populate-action`, `data-quality-control-action`, `semantic-uplifting-action`, `subsetted-distribution-creation-action`
- **1 custom VLIZ action**: `vliz-be-opsci/rocrate-to-pages` — this one's especially relevant, since it's made by your own team (VLIZ), not the broader EMO-BON org

## How this maps to the 4-phase pipeline

| Action | Phase | What it does |
|---|---|---|
| `populate-action` | Phase 1 | Google Sheets → raw CSV — cloned and ran this ourselves in `bpns-workflow-local` |
| `data-quality-control-action` | Phase 2 | Raw → Filtered (see `4.data-pipeline-stages.md`) — not yet run locally |
| `semantic-uplifting-action` | Phase 3 | Filtered → Transformed / RDF (see `2.rdf-rdfs-sosa.md`, `3.semantic-mapping.md`) — not yet run locally |
| `subsetted-distribution-creation-action` | — | Packages a filtered subset of data for external aggregators (e.g. Blue-Cloud) — not part of the 4 core phases we're tracking |
| `vliz-be-opsci/rocrate-to-pages` | Phase 4 | Publishes the RO-Crate as a web page — not yet run locally |
