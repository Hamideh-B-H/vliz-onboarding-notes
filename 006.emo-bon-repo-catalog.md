## Actions (7)

Reusable GitHub Actions called by every observatory's workflow.yml. (See `7.emo-bon-actions-used.md` for how these map to the 4-phase pipeline.)

| **Repo** | **Purpose** |
| --- | --- |
| populate-action | Downloads Google Sheets logsheets, converts to raw CSV |
| data-quality-control-action | Validates and cleans logsheet data, opens QC issues |
| semantic-uplifting-action | Converts cleaned CSV into RDF/RO-Crate linked data |
| subsetted-distribution-creation-action | Packages a filtered subset of data for external aggregators (e.g. Blue-Cloud) |
| repo-constructor-action | Constructs new observatory repos |
| ena-sample-registration-action | Registers sample accessions in ENA (European Nucleotide Archive) |
| rocrate-metadata-generator-action (archived) | Formerly created RO-Crate JSON files |

## Profiles (3)

Define the structure/templates used to semantically uplift data into RDF.

- observatory-profile — templates for observatory logsheet data
- analysis-results-profile — profile for MetaGOflow analysis outputs
- sequencing-profile — profile for sequence metadata

## Naming Convention Reference

| **Suffix** | **Meaning** |
| --- | --- |
| -crate | An actual RO-Crate holding real data |
| -profile | Defines the structure/templates a crate conforms to |
| -action | A reusable GitHub Action |
| -docker | Builds a Docker image |
| -book | A larger body of documentation |
| -example | Playground/test repo |
| .github.io | Website repo |
