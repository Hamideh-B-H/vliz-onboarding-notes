# VLIZ Python Conventions — Practical Reference

A working reference for writing Python code on VLIZ / EMO-BON projects. Source: open-science.vliz.be/conventions/python

## Quick command cheat sheet

| **When** | **Command** | **What it does** |
| --- | --- | --- |
| Right after cloning (once) | make init-dev | Installs Poetry deps + pre-commit hook |
| Before committing | make lint-fix | Auto-fixes formatting (Black + isort) |
| Manual double-check | make lint-check | Runs Flake8 — reports remaining issues |
| Before opening a PR | make test-coverage | Runs tests, checks coverage targets |
| Committing | git commit -m "..." | Pre-commit hook auto-checks — blocks if it fails |

## 1. Dependency manager: Poetry

Install once, globally:
```
curl -sSL https://install.python-poetry.org | python3 -
```

Use per-project, whenever a repo has a pyproject.toml:
```
git clone <repo-url>
cd <repo-folder>
poetry install   # isolated env, exact locked versions
poetry shell      # activate that project's environment
```

- pyproject.toml — replaces requirements.txt + setup.py
- poetry.lock — auto-generated, locks exact versions for reproducibility
- poetry add <package> — adds and records a new dependency

## 2. Linting & formatting

| **Tool** | **Role** | **Fixes automatically?** |
| --- | --- | --- |
| Black | Code formatter | Yes |
| isort | Import sorter | Yes |
| Flake8 | Linter (style/quality checks) | No — reports only |

VLIZ-specific setting: max line length = 79 characters (stricter than Black's default of 88).
```
black .    # auto-formats code
isort .    # auto-sorts imports
flake8     # reports what needs manual fixing
```

## 3. Testing — coverage targets

- Overall project coverage: at least 90%
- Per-file minimum: at least 85% (prevents one poorly-tested file hiding under a good average)
```
make test-coverage
```
This is also one of the required automated checks before a PR can be merged.

## 4. Project template (cookiecutter)

Don't start Python projects from an empty folder — use the official VLIZ template (Poetry, linting config, Makefile, and pre-commit hook already set up):
```
pip install cookiecutter
cookiecutter https://github.com/vliz-be-opsci/cookiecutter-py-module
```

## 5. Enforcement: Makefile + pre-commit hook

The Makefile provides the make <command> shortcuts above. The pre-commit hook (installed by make init-dev) runs automatically on every git commit — if checks fail, the commit is blocked.

Typical day-to-day rhythm:
```
git clone repo      -> make init-dev        (once)
write/edit code      -> make lint-fix          (before each commit)
git commit             -> pre-commit hook auto-checks
before opening a PR     -> make test-coverage
```

## 6. Documentation: Sphinx

Docstrings should follow Sphinx markup so documentation can be auto-generated from the code itself.

```python
def calculate_discount(price: float, is_member: bool) -> float:
    """
    Calculate the final price after applying a membership discount.

    :param price: The original price before discount.
    :param is_member: Whether the customer is a paying member.
    :return: The discounted price if a member, otherwise the original price.
    """
    if is_member:
        return price * 0.9
    return price
```

## 7. Code authoring style — four rules

| **Rule** | **Don't** | **Do** |
| --- | --- | --- |
| snake_case | myVariable, calculateTotal() | my_variable, calculate_total() |
| pathlib over os.path | os.path.join("data","raw.csv") | Path("data") / "raw.csv" |
| f-strings | "Hello %s" % name | f"Hello {name}" |
| Type hints everywhere | def calc(price, qty): | def calc(price: float, qty: int) -> float: |

## 8. Design by Contract

Treat each function as a contract with its caller — document it explicitly rather than leaving it implicit:

- Pre-conditions — what must be true before calling it
- Post-conditions — what's guaranteed to be true after it runs
- Invariants — things that are always true throughout
- Declared exceptions — what errors it may raise, and when

Enforced in practice through:

- _underscore_prefix — marks something private, not part of the promised contract
- ABC (Abstract Base) classes — define required method signatures without implementation
- Limited __init__.py exposure — only intentionally expose the public contract

## Full example — all conventions applied together

```python
from pathlib import Path

def filter_logsheets(data_model: dict, threshold_date: str) -> dict:
    """
    Filter out logsheet rows collected on or after the threshold date.

    :param data_model: Dict of DataFrames keyed by logsheet alias.
    :param threshold_date: ISO date string (YYYY-MM-DD).
    :return: A new dict with rows filtered.
    :raises KeyError: if 'collection_date' column is missing.
    """
    output_path = Path("logsheets") / "filtered"
    filtered = {}
    for alias, df in data_model.items():
        filtered[alias] = df[df["collection_date"] < threshold_date]
        print(f"Filtered {alias}: {len(filtered[alias])} rows kept")
    return filtered
```
