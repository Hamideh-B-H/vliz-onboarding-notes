## Semantic web / RDF concepts

| Link | What it is |
|---|---|
| [RDF Primer (W3C)](https://www.w3.org/TR/rdf11-primer/) | Starting point for RDF itself |
| [DCAT (W3C)](https://www.w3.org/TR/vocab-dcat-3/) | Data Catalog Vocabulary — not yet explored (Marc) |
| [RO-Crate](https://www.researchobject.org/ro-crate/) | Packaging format for bundling data + machine-readable metadata (JSON-LD). General-purpose — not biology-specific, and doesn't require semantic uplifting. EMO-BON happens to use it *after* uplifting data to RDF, but that's EMO-BON's choice, not part of what RO-Crate itself is (Marc) |
| [JSON-LD spec](https://www.w3.org/TR/json-ld/) | Format `ro-crate-metadata.json` is written in |
| [schema.org](https://schema.org/docs/gs.html) | General-purpose metadata vocabulary (Marc) |
| [Darwin Core](https://dwc.tdwg.org/) | Biodiversity-specific vocabulary |
| [Dublin Core](https://www.dublincore.org/) | General resource metadata — Darwin Core extends this |
| [SOSA (W3C)](https://www.w3.org/TR/vocab-ssn/) | Describes the sampling process itself |
| [Knowledge Graph Building (Semantic Uplifting)](https://data.emobon.embrc.eu/data-workflow-book/kg-building/) | Handbook page specifically on Phase 3 — save for when we actually run `semantic-uplifting-action` |
